Every account on SokoPlus has a role that controls what you can see and do. Here's each role in plain language.

## Client (Buyer)

The end consumer. Clients browse the marketplace, place orders, book services, track deliveries and leave reviews.

- Access to cart, wishlist, orders and addresses
- Can confirm receipt of an order
- Can submit feedback after an order is delivered

## Vendor

Sells physical products. Vendors manage their inventory, fulfil orders, assign a delivery team and run promotions.

- Product listing and inventory management
- Order fulfilment with recipient verification
- Delivery team and delivery zones management
- Coupons, flash sales and shop boosts (where enabled)

## Service provider

Offers professional services instead of (or in addition to) products.

- Service listing with pricing
- Booking management (accept / reject / complete)
- Working hours management
- Can also sell physical products

## Delivery partner

Carries out deliveries on behalf of vendors.

- View assigned deliveries
- Verify recipient identity or QR code at handover
- Toggle active / offline availability
- View personal delivery stats

## Admin roles

| Role | Scope |
|------|-------|
| **partnerAdmin** | Day-to-day operations: users, vendors, orders, categories, content, reports. |
| **majorAdmin** | Everything a partnerAdmin can do, plus regional management, notes, flags, tasks and support tickets. |
| **superAdmin** | Full system access, including records, system health and database management. |

Each admin role starts with a **default set of abilities**. A Super Admin can then adjust a single admin (allow or deny one ability) or change the defaults for a whole role. Some abilities are deliberately kept apart:

- **Permissions, regions and region assignment** — only a Super Admin can hand these out, so delegation can never quietly turn into escalation.
- **Region scope** — an admin tied to a region only acts on accounts in that region.

See **Who can do what — admin permissions** for the full, plain-language explanation.

## The dashboard

Each role gets a personalised dashboard with tabs relevant to that role. For example, a client sees *Orders* and *Wishlist* tabs, while a vendor sees *Products*, *Inventory* and *Delivery Team*.

See the role-specific guides under **Help Centre** for how to use each dashboard.
