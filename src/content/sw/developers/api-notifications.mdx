Endpoints hizi zinashughulikia mawasiliano baina ya watumiaji na maudhui ya jukwaa.

## Arifa (`/api/notifications`)

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| GET | `/notifications` | JWT | Arifa zako |
| PUT | `/notifications/:id/read` | JWT | Weka alama ya kusoma kwa arifa moja |
| PUT | `/notifications/read-all` | JWT | Weka alama ya kusoma zote |
| DELETE | `/notifications/clear` | JWT | Futa zote |
| POST | `/notifications/register-token` | JWT | Sajili tokeni ya Expo, au usajili wa web-push kwa `type: "web"` |
| GET | `/notifications/preferences` | JWT | Pata mapendeleo |
| PUT | `/notifications/preferences` | JWT | Sasisha mapendeleo |
| POST | `/notifications` | `send_messages` | Tuma kwa `userId`, `userIds` au `roles` |

Mapendeleo: `order_updates`, `promotions`, `general`, `channel` (`sms`/`email`).

## Ujumbe (`/api/messages`)

Mazungumzo ya moja kwa moja pekee. Yanahitaji swichi ya kipengele `messaging`.

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| POST | `/messages` | JWT | Tuma ujumbe wa moja kwa moja (`receiverId`, `content`, `attachment` si lazima) |
| GET | `/messages/conversations` | JWT | Mazungumzo + idadi ya ujumbe usiosomwa (`page`, `limit`) |
| GET | `/messages/conversations/:id/messages` | JWT | Ujumbe wa mjadala (`before`, `limit`) |
| PUT | `/messages/conversations/:id/read` | JWT | Weka alama ya kusoma mazungumzo |
| GET | `/messages/conversations/:id/catalog` | JWT | Bidhaa/huduma za mshiriki mwingine |
| GET | `/messages/unread/count` | JWT | Jumla ya ujumbe usiosomwa |
| GET | `/messages/recipients/search` | JWT | Tafuta wapokeaji (`q`, `limit`) |

Modeli ya `Conversation` pia huhifadhi aina za channel za msimamizi na CustomerCare, lakini ni njia za ujumbe wa moja kwa moja zilizo hapo juu pekee zilizowekwa kwenye API kwa sasa. Tazama **Mazungumzo na ujumbe** kwa modeli na hali ya uenezaji.

## Maudhui na msaada (`/api/content`)

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| GET | `/content/platform/:key` | Public | Ukurasa wa CMS (faragha, sheria) |
| PUT | `/content/platform/:key` | superAdmin | Unda au sasisha ukurasa wa CMS |
| GET | `/content/faq` | Public | FAQs zinazotumika |
| GET | `/content/faq/all` | partnerAdmin+ | FAQs zote |
| POST/PUT/DELETE | `/content/faq...` | partnerAdmin+ | CRUD ya FAQ |
| POST | `/content/support/tickets` | JWT | Unda tikiti |
| GET | `/content/support/tickets` | JWT | Tikiti zako |
| GET | `/content/support/tickets/all` | partnerAdmin+ | Tikiti zote |
| PUT | `/content/support/tickets/:id` | partnerAdmin+ | Sasisha hali |
| POST | `/content/support/tickets/:id/reply` | partnerAdmin+ | Jibu |
