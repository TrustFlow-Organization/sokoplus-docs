Endpoints hizi zinahitaji kipindi cha `superAdmin`. Vipindi vya msimamizi wa kawaida haviwezi kuona ukurasa huu.

## Watumiaji, wauzaji na maagizo ya msimamizi mkuu

| Method | Path | Auth | Maelezo |
|--------|------|------|---------|
| DELETE | `/admin/users/:id` | superAdmin | Futa mtumiaji kwa upole |
| PUT | `/admin/vendors/:id/toggle-products` | superAdmin | Washa/zima uorodheshaji wa bidhaa |
| DELETE | `/admin/orders/:orderId` | superAdmin | Futa agizo kwa soft delete |

## Fedha na rekodi

| Method | Path | Auth | Maelezo |
|--------|------|------|---------|
| GET | `/admin/commissions` | superAdmin | Orodha ya komisheni |
| PUT | `/admin/commissions/:id/pay` | superAdmin | Weka alama ya komisheni iliyolipwa |
| GET | `/admin/refunds` | superAdmin | Maombi ya kurudishiwa fedha |
| POST | `/admin/refunds/:id/approve` | superAdmin | Idhinisha kurudishiwa fedha |
| POST | `/admin/refunds/:id/reject` | superAdmin | Kataa kurudishiwa fedha |
| GET | `/admin/records` | superAdmin | Rekodi zilizofutwa kwa upole |
| POST | `/admin/records/:model/:id/restore` | superAdmin | Rejesha rekodi |

## Rufaa, mikopo na usajili

| Method | Path | Auth | Maelezo |
|--------|------|------|---------|
| GET | `/referrals/admin/all` | superAdmin | Rufaa zote (kwa kurasa) |
| GET | `/credits/admin/user/:userId` | superAdmin | Salio la mikopo na miamala ya mtumiaji |
| POST | `/credits/admin/adjust` | superAdmin | Rekebisha mikopo ya mtumiaji kwa mikono |
| GET | `/subscriptions/all` | superAdmin | Usajili wote pamoja na taarifa za wamiliki |

## Flash sales

| Method | Path | Auth | Maelezo |
|--------|------|------|---------|

| PATCH | `/flash-sales/admin/participant/:id/approve` | superAdmin | Idhinisha mshiriki |
| PATCH | `/flash-sales/admin/participant/:id/reject` | superAdmin | Kataa mshiriki |

## Ufagio wa escrow

| Method | Path | Auth | Maelezo |
|--------|------|------|---------|
| POST | `/escrow/process-expired` | superAdmin | Fagia escrow zilizoisha muda |

## Mfumo (superAdmin)

| Method | Path | Maelezo |
|--------|------|---------|
| GET | `/admin/system/health` | Ucheleweshaji wa hifadhidata, CPU, kumbukumbu, idadi |
| POST | `/admin/clear-database` | Futa majedwali yote (inahitaji nenosiri) |
| POST | `/admin/clear-database/selective` | Futa majedwali yasiyo muhimu |
| GET | `/admin/ecommerce` | Swichi zote za vipengele |
| PUT | `/admin/ecommerce/:id` | Badilisha swichi ya kipengele |
| GET | `/admin/map/data` | Data ya eneo kwa ramani ya msimamizi |
| GET | `/admin/scan/:id` | Tafuta ID kwenye majedwali yote |

> **Onyo:** `clear-database` inaharibu data na inahitaji nenosiri. `superAdmin` pekee.
