Arifa zinawafanya watumiaji kuwa na taarifa. Backend huzitoa kupitia njia tatu: **ndani ya programu (in-app)**, **Expo push** (simu), na **web push** (kivinjari).

## Njia

| Njia | Utaratibu | Lini |
|---------|-----------|------|
| In-app | Safu za `Notification` + socket.io emit | Daima |
| Expo push | `expoPushToken` kwenye mtumiaji, `expo-server-sdk` | Programu za simu |
| Web push | `WebPushSubscription` + maktaba ya web-push (VAPID) | Kivinjari |

## Kujisajili kwa push

Simu na wavuti zote hutumia endpoint moja, `POST /api/notifications/register-token`:

```bash
# Simu (tokeni ya Expo)
curl -X POST https://api.sokopluss.co.tz/api/notifications/register-token \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"token": "ExponentPushToken[...]"}'

# Wavuti (usajili wa push)
curl -X POST https://api.sokopluss.co.tz/api/notifications/register-token \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"type": "web", "endpoint": "...", "p256dh": "...", "auth": "..."}'
```

Kwa web push, tumia `type: "web"` pamoja na `endpoint`, `p256dh` na `auth` za usajili. Bila `type`, `token` huhifadhiwa kama tokeni ya Expo ya mtumiaji.

## Mapendeleo

Watumiaji wanaweza kukandamiza aina za arifa kupitia `GET/PUT /api/notifications/preferences`.

| Mapendeleo | Hudhibiti |
|------------|----------|
| `order_updates` | Hali ya agizo, usafirishaji, escrow |
| `promotions` | Matangazo, kukuza tangazo, kuponi |
| `general` | Mengine yote |
| `channel` | `sms` (chaguo-msingi) au `email` kwa ujumbe usio wa push |

## Kinachochochea arifa

- Agizo limewekwa / hali imebadilika
- Usafirishaji umekabidhiwa / umethibitishwa
- Ujumbe mpya
- Uidhinishaji / ukataliwa wa muuzaji
- Matukio ya malipo au kurudishiwa fedha
- Mabadiliko ya swichi za vipengele (yatangazwa kwa hadhira)

## Kutuma arifa (msimamizi)

Wasimamizi wenye ruhusa ya `send_messages` hutuma arifa kwa mtu mmoja au kwa jukumu kupitia endpoint moja:

| Mbinu | Njia | Maelezo |
|--------|------|-------------|
| POST | `/api/notifications` | Tuma kwa `userId`, `userIds` au `roles` |

```json
{
  "roles": ["vendor"],
  "type": "admin",
  "title": "Taarifa ya jukwaa",
  "message": "Viwango vipya vya komisheni vinaanza Jumatatu."
}
```

Jibu hurudisha `count`, `smsSent`, `emailSent`, `pushSent` na `webPushSent`. Uteuzi wa majukumu una mipaka kwa jukumu la mtumaji: `superAdmin` anaweza kulenga kila jukumu, ilhali `majorAdmin` na `partnerAdmin` wanaweza kulenga kundi dogo.

<Callout type="note">
Matangazo ya majukumu hutumwa kwa kila mtumiaji na tokeni iliyosajiliwa. Tumia `userId` au `userIds` kwa arifa mahususi.
</Callout>

## Vidokezo vya usalama

- Usiwahi kuweka kwenye logi `expoPushToken` au funguo za faragha za VAPID.
- Funguo za VAPID zinapaswa kuwa kwenye vigezo vya mazingira (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`).
- Heshimu mapendeleo ya watumiaji kabla ya kutuma push za matangazo.
